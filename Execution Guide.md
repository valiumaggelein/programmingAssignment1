# Execution Guide

## Language of Choice
- Python

## How to run
Using `python3`:
```sh
python3 resourceManager.py
python3 synchronizationFix.py
python3 blockingFix.py
python3 monitorFix.py
```
Using `uv`:
```bash
uv run resourceManager.py
uv run synchronizationFix.py
uv run blockingFix.py
uv run monitorFix.py
```
